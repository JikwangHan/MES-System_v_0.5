# E2E 자동화 최소 세트 (초안)

## 도구 제안
- Cypress (또는 Playwright)로 빠른 시나리오 테스트
- 위치: `test/e2e` (추가 예정)

## 우선 자동화할 시나리오(3건)
1) **권한 차단 모달**
   - 계정: USER
   - 경로: `/app/admin/users` 직접 진입
   - 기대: 모달 1회 표시 → 확인 시 토큰 삭제 + 홈 이동
   - 검증: 로컬스토리지 `access_token` 삭제 여부, 추가 모달 없음

2) **검색/초기화 동작**
   - 화면: 설비 모니터링(또는 수주/재고)
   - 절차: 검색 값 입력 → 검색 → 초기화
   - 기대: 입력 필드 모두 초기화, 리스트 기본 조회 상태로 복귀

3) **대시보드 기간 반응**
   - 화면: 대시보드
   - 절차: 기간 `오늘` → `최근7일` → `최근30일` 순서 전환
   - 기대: KPI/차트/최근수주 리스트가 기간에 맞게 값 또는 범위 변동

## 실행 예시(Cypress 기준)
```bash
cd client
npm install --save-dev cypress
npm run cypress open   # 혹은 npm run cypress run
```

## 향후 확장 아이디어
- 회사 코드 전환(ALL ↔ 특정 업체) 시 각 화면 재조회 여부 확인
- COMPANY_ADMIN 권한으로 사용자 관리 접근 허용, 업체 관리 차단
- 버튼 크기/정렬 스냅샷 체크(디자인 회귀 방지)
