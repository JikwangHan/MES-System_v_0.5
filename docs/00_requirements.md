# 프로젝트 공통 요청사항 정리 (항상 준수할 원칙)

본 문서는 MES-System_v_0.5 개발 동안 항상 지켜야 할 요청사항을 정리한 것입니다. 모든 작업 시 이 문서를 참조하며, 추가 요청사항이 생기면 아래 항목을 보태어 관리합니다.

## 현재까지 접수된 요청사항
- **한글, 상세 설명**: 모든 질의·응답과 주석을 한글로, 초보자도 이해할 수 있도록 매우 자세히 작성한다.
- **엄격한 검증/테스트**: 진행 과정마다 자체 혹독한 테스트와 검증을 수행해 에러·경고 없는 상태를 목표로 한다.
- **주석 필수**: 개발 중 주석을 항상 작성하고, 한글로 상세히 설명한다(의도와 동작을 초보자도 알 수 있게).
- **단일 exe 배포**: 최종 배포 시 DB를 포함해 단일 exe 파일만으로 시스템이 구축되도록 패키징 전략을 마련한다.
- **MES_Simulator 연동**: 기존 MES 연동 제조장비(자동포장장비) 시뮬레이터(MES_Simulator / Smart-Factory_Simulator)와 연동 가능한 구조로 설계·구현한다. 향후 다른 장비 연동도 고려한다.
- **Smart-Factory_Monitoring 연동**: 다양한 장비와의 연동(통신 방식, 데이터 형식 등)을 고려하여 설계·구현한다.
- **UI/UX 기준**: `docs/2025년 MES 웹서버 사용설명서.pdf`에 있는 화면 이미지를 기준으로 UI/UX를 구현한다.
- **오픈소스 S/W 사용**: DBMS, Grid, Chart 등은 널리 쓰이고 사용이 간단하며 디자인이 우수한 무료 오픈소스를 채택하고, 최종 배포판에 자동 적용되도록 구성한다.

## 운영 방법
- 새로운 요청사항이 생기면 이 파일에 항목을 추가하고, 버전/날짜를 간단히 기록하여 추적한다.
- 모든 설계·구현·테스트 단계에서 본 문서를 재확인하여 누락되는 요구가 없도록 한다.
